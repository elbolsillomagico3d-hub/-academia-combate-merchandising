ACADEMIA DE COMBATE MERCHANDISING
==================================

Primera versión de la tienda web.

Incluye:
- Camiseta Frontier
- Colores: azul marino, negro, verde oliva/militar y verde
- Tallas S, M, L, XL y 2XL
- Precios con envío incluido:
  * Península: 16,90 €
  * Baleares: 21,80 €
  * Canarias: 22,90 €
- Carrito
- Datos de cliente y dirección
- Selección de Bizum o transferencia
- Imágenes proporcionadas

IMPORTANTE:
Esta primera versión todavía NO envía el pedido a ningún sitio. El siguiente paso es conectar el formulario a Firebase/Google Sheets/email/WhatsApp y poner el número de Bizum y el IBAN reales.

Para publicar gratis:
1. Crea un repositorio en GitHub.
2. Sube index.html y la carpeta assets.
3. Activa Settings > Pages > Deploy from branch.
